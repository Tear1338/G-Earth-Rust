Do not use the upstream main archive as the oracle: its circular imports fail before connection.

The scheduler supports finite and explicitly indefinite jobs, per-job pause/resume/removal, editing active jobs by stable identity and editable saved templates. Editing a running job preserves its pause state and leaves templates unchanged. Jobs are retained during a transient disconnection and resume on reconnection; explicit Stop still clears them. An enqueue failure does not consume the failed repetition, but an accepted queue item is not proof that the remote received it. It imports and exports beta-29 tab-separated `.sched` files, preserving packet text, direction, offset and paused state; import replaces templates but never starts jobs. Export rejects finite or relative templates that the Java format cannot represent without changing behavior. Editing a template does not change active jobs; changes require saving settings. An optional offset aligns sends to the Unix clock and detects clock changes above a tolerance of the smaller of 20 ms or half the interval; it recalculates the next future deadline, skips missed sends and keeps relative jobs unaffected. It rejects an offset equal to the interval (the Java UI accepts that value but it never matches a timestamp). The upstream scheduler can replay missed deadlines while the Rust implementation deliberately avoids bursts. Exact persistence semantics remain. Other missing areas include real firewall/alias and Raw-IP multi-instance client validation, non-Windows privileged helpers, QtConsole visual validation, exact UI/shortcuts/tray behavior, full localization and validation with real client sessions and G-Presets. Whole-application performance remains unmeasured; PERFORMANCE.md covers only packet construction.

Native Rust parsers now cover room entities, movement, floor/wall furniture, inventory pages, all eight furniture state variants, profiles/friends, catalog, navigator and forum overviews. The released Java API supplies finite packet and decoded-value comparisons for state formats, furniture, friends, catalog, navigator and a forum comment. The original Java inventory page constructor has edge-case pagination defects; Rust uses complete pages of at most 600 items. The remaining parser APIs need implementation and wider differential tests. EVA packet mutations include typed fixed-width fields, one string, bulk exact strings and integers, with finite Java comparisons of packet bytes and cursor. They reject header writes, malformed input, unsupported WEDGIE mutations and non-Latin-1 text; a cursor past a shortened packet is clamped, whereas Java may leave it out of bounds. The Java replacement can corrupt the byte after an empty string when growing it; Rust preserves that following byte, covered by a regression test. Substring/regex and alternate charset helpers remain unimplemented.

Structure prediction now ports the beta-29 heuristics for classic and Unity packets, with bounded scan/expansion and nested metadata structures. Extension packet-to-string requests and the logger use known structure when available and prediction otherwise. The logger has saved options for additional packet data, separators and lazily rendered expressions; it invalidates cached expressions on metadata updates. WEDGIE prediction is unavailable. Differential checks against the original Java API cover 24 prediction samples, selected nested/number expressions and direction-specific metadata with duplicate identifiers. Larger or unusually costly input is bounded and can yield an empty expression.
